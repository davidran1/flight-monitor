# ✈️ מערכת ניטור והתראות טיסות Etihad Airways (TLV ⇄ HKT)

מערכת חכמה, מהירה ועצמאית לחלוטין לסריקה, זיהוי והתראה על טיסות **Etihad Airways** מתל אביב (TLV) לפוקט (HKT) בחודשים **ינואר ופברואר**.

### 🌟 יתרון ענק: אפס תלות ב-API בתשלום או בפורטלים סגורים!
המערכת שודרגה לפעול ישירות מול מנוע הטיסות החי של **Google Flights**.  
**אין צורך במפתחות API, אין צורך בהרשמה לשירותים חיצוניים (כמו Amadeus), ואין עלויות חודשיות!**

---

## 🎯 תכונות המערכת

- **סינון מדויק לפי הדרישות:**
  - חברת תעופה: **Etihad Airways** בלבד (קוד טיסה EY).
  - זמן טיסה כולל: **עד 15 שעות** לכל כיוון (כולל עצירת הביניים באבו דאבי - AUH).
  - משך שהות: **15 עד 25 ימים** בפוקט.
  - חלון זמנים: חודשים **ינואר ופברואר**.
- **זיהוי טיסות חדשות:** ברגע שנוספת טיסה חדשה שלא הייתה קיימת במאגר – נשלחת התראה מיידית.
- **זיהוי ירידות מחיר:** המערכת משווה למחיר ההיסטורי ומזהה כל ירידת מחיר.
- **התראות מייל עשירות:** מייל מעוצב ב-HTML בעברית עם שעות טיסה, זמני קונקשן, פירוט חסכון במחיר, וכפתור ישיר להזמנה באתר הרשמי של איתיחאד.

## 🚀 הגדרה מהירה (רק צעד אחד!)

כל מה שצריך כדי לקבל התראות למייל:

1. היכנס להגדרות האבטחה של גוגל: [Google App Passwords](https://myaccount.google.com/apppasswords).
2. צור סיסמה חדשה בת 16 תווים (למשל תחת השם `FlightAlerts`).
3. פתח את הקובץ [.env](file:///c:/projects/flight/.env) והזן את הפרטים:
   ```ini
   EMAIL_ENABLED=true
   SMTP_HOST=smtp.gmail.com
   SMTP_PORT=587
   SMTP_USER=your_email@gmail.com
   SMTP_PASSWORD=abcd efgh ijkl mnop
   EMAIL_TO=recipient@example.com
   ```
4. בדוק את תקינות המייל:
   ```powershell
   python main.py --test-email
   ```

## 💻 פקודות הפעלה

### 1. ביצוע סריקה מלאה עכשיו (Scan Mode)
סורק בזמן אמת את כל קומבינציות התאריכים, שומר ב-DB ושולח התראה על כל טיסה חדשה או ירידת מחיר:
```powershell
python main.py --scan
```

### 2. הפעלת ניטור רציף ברקע (Watch Mode)
המערכת תמשיך לרוץ ברקע ותבצע סריקה תקופתית (למשל כל 60 דקות):
```powershell
python main.py --watch --interval 60
```

### 3. צפייה בסיכום המאגר ובטיסות הזולות ביותר (Summary)
מציג דשבורד בטרמינל עם סך הטיסות, טווח המחירים, ו-5 הטיסות הזולות ביותר:
```powershell
python main.py --summary
```

### 4. הרצת הדמיה (Mock Mode) לבדיקה ללא רשת
```powershell
python main.py --test-mock
```
